# 🎮 Vaan-CFG Gaming Catalog

Catálogo interactivo de juegos de PlayStation 5 con más de 340 títulos.

## Características

- 📊 **347 juegos totales** (207 poseídos + 140 faltantes)
- 🔍 **Búsqueda en tiempo real** por nombre o género
- 🎯 **Filtros interactivos** (Todos, Poseídos, Faltantes)
- 📱 **Diseño responsive** - Funciona en cualquier dispositivo
- 💾 **Información técnica** - Género y peso de instalación
- 🌐 **100% Offline** - Funciona sin internet
- ⚙️ **Powered by Vaan-CFG**

## Cómo usar

1. Abre `index.html` en tu navegador
2. Usa los filtros para ver juegos específicos
3. Busca por nombre o género
4. ¡Disfruta tu catálogo!
